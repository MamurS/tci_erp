## Tuzilma

- **Butun aylanmaga** — sug‘urtalanuvchining barcha bayerlari qoplanadi (limitlar va diskretsion limit doirasida).
- **Asosiy bayerlar** — faqat nomlangan bayerlar qoplanadi.

## Shartlar

| Shart | Nimani anglatadi |
|---|---|
| {{term:insured-percentage|Qoplash foizi}} | Sug‘urtalovchi qoplaydigan zarar ulushi, odatda 80–90 %. |
| {{term:nql|Qoplanmaydigan zarar (NQL)}} | Chegara: undan kichik zarar umuman qoplanmaydi; unga teng zarar to‘liq, chegirmasiz qoplanadi. |
| {{term:deductible|Franshiza}} | Har bir zarardan qoplash foizidan keyin chegiriladigan summa. |
| {{term:afl|Agregat franshiza}} | Davr ichidagi zararlar summasi, uni sug‘urtalanuvchi o‘zi ko‘taradi; uning qoldig‘i chegiriladi. |
| {{term:max-liability|Javobgarlikning maksimal limiti}} | Polis bo‘yicha barcha to‘lovlar chegarasi, odatda mukofotga karrali. |
| {{term:dl|Diskretsion limit}} | Shu summagacha sug‘urtalanuvchi bayerni limitsiz o‘zi baholaydi. |
| Kutish davri | Muddati o‘tganidan necha kun keyin da’vo topshirish mumkin. |
| Maksimal to‘lov muddati | Undan uzunroq muddatli hisob-fakturalar qoplanmaydi. |

## Tovon hisobi tartibi

Qoplangan qarz → NQL chegarasi → × qoplash foizi → − franshiza → − agregat franshiza qoldig‘i → javobgarlikning maksimal limiti qoldig‘idan oshmaydi. Batafsil — {{link:claims-coverage}}.
