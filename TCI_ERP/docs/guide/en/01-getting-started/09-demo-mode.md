Demo mode shows training data instead of the working data: made-up companies, policies, limits, claims and tasks. Whatever you do in demo mode stays in the demo data, and the working data is not shown meanwhile.

## Switching it on and off

The **{{ui:demo.mode.label}}** switch is in three places:

1. the user menu, top right;
2. the {{ui:account.title}} page;
3. the dashboard, as the **{{ui:demo.mode.enter}}** button on the blue band.

While it is on, a yellow bar runs above every page and the top bar shows a **{{ui:demo.mark}}** mark. **{{ui:demo.banner.leave}}** on that bar takes you back to the working data.

Demo records are easy to spot: company names start with "DEMO", policy numbers with "DEMO-". The mode is yours alone: colleagues do not see it.

## Demonstration accounts

Every role has a demo account (an address ending in @demo.invalid). It always works in the demo data and cannot switch the mode off.

> [!DEMO]
> The administrator loads and removes the demo data: {{ui:nav.admin}} › {{ui:admin.tabs.demo}}. If the lists are empty in demo mode, ask the administrator to load the demo set.
