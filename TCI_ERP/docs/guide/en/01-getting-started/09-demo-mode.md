Demo mode lets you learn and show the system on training data without touching the real data.

## How to switch it on

1. Open the user menu, top right.
2. Switch on **Demo mode**.
3. A yellow **DEMO** bar appears at the top of the screen: while you see it, you are working with demo data.

Demo records are easy to spot: company names and other names start with **DEMO**. Switch the mode off in the same user menu.

> [!DEMO]
> The administrator loads and removes the demo data: {{ui:nav.admin}} › Demo data. If the lists are empty in demo mode, ask the administrator to load the demo set.
