## When to use it

You need a limit on a new buyer, or a different limit on a known one.

## Steps

1. {{ui:portal.nav.limits}} › {{ui:portal.limits.request}}. Find the buyer by name (at least 3 letters). Not in the list — propose them by name: the insurer registers the company.
2. Enter the amount, currency, payment terms and the justification. The form tells you whether the amount is within the policy's discretionary limit.
3. While underwriting has not taken the request, you can **change** it — {{ui:portal.limits.change.action}} — the amount, the terms or the justification.
4. After that, a change is a replacement: the old request is withdrawn and a new one sent at the same time.
5. Any open request can be **withdrawn** — {{ui:portal.limits.change.withdraw}}.

## Result

Every change is kept and visible to the insurer.

## Common mistakes

- **A second request on the same buyer.** One policy may have only one open request per buyer — change the existing one.
