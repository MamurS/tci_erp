## Когда использовать

Нужен лимит на нового байера или другой лимит на прежнего.

## Шаги

1. {{ui:portal.nav.limits}} › {{ui:portal.limits.request}}. Найдите байера по названию (не меньше 3 букв). Нет в списке — предложите по названию: страховщик заведёт организацию сам.
2. Укажите сумму, валюту, срок отсрочки и обоснование. Форма подскажет, укладывается ли сумма в дискреционный лимит полиса.
3. Пока заявку не взяли в работу, её можно **изменить** — {{ui:portal.limits.change.action}} — сумму, срок или обоснование.
4. После этого изменение — это замена: прежняя заявка отзывается и одновременно подаётся новая.
5. Любую открытую заявку можно **отозвать** — {{ui:portal.limits.change.withdraw}}.

## Результат

Каждое изменение сохраняется и видно страховщику.

## Частые ошибки

- **Вторая заявка на того же байера.** По одному полису на одного байера может быть только одна открытая заявка — измените существующую.
