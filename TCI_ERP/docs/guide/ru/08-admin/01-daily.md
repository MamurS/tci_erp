## Когда использовать

Ежедневно и по запросам сотрудников.

## Шаги

1. {{ui:nav.agenda}}: свои задачи — напоминание обновить список ОЭСР и другие технические.
2. {{ui:nav.admin}} › {{ui:admin.tabs.security}}: блокировки входа, предупреждения, сеансы.
3. Запросы сотрудников: новые пользователи, роли, сброс пароля, разблокировка.
4. Курсы валют и справочники — по мере необходимости.

## Результат

Все работают в своих ролях; заблокированных учётных записей без причины нет.

## Частые ошибки

- **Пытаться «помочь» решением по лимиту.** Администратор решений не принимает — база данных отклонит.
