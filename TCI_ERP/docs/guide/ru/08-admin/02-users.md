## Когда использовать

Новый сотрудник, смена обязанностей, забытый пароль, блокировка.

## Шаги

1. {{ui:nav.admin}} › {{ui:admin.tabs.users}}.

{{shot:admin-users}}

2. Роли: отметьте одну или несколько. Роль клиента не совмещается ни с какой другой. Пользователь работает в одной роли за раз и переключается через рабочие пространства.
3. Кредитному аналитику можно поставить отметку «старший» — он задаёт рейтинги групп и утверждает внутренние страновые категории.
4. Руководитель сотрудника, блокировка и разблокировка, сброс пароля (пользователь сменит временный пароль при входе).
5. Создание пользователей идёт через сервис подготовки пользователей. Пока он не размещён, экран показывает «сервис недоступен», и учётные записи создаются вручную по инструкции владельца системы.

## Результат

Пользователь видит рабочие пространства своих ролей.

## Частые ошибки

- **Выдать себе бизнес-роль, чтобы что-то «поправить».** Бизнес-действия должны делать сотрудники отделов: так сохраняется правило четырёх глаз.
