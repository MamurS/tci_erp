**Почему я вижу экраны отделов, но не могу ничего изменить?**
Администратор видит рабочие экраны только для контроля. Все бизнес-действия закрыты в базе данных.

**Как разблокировать пользователя после неудачных попыток входа?**
{{ui:admin.tabs.security}} › блокировки › разблокировать. Разблокировка требует, чтобы блокировка была действующей.

**Где включается второй фактор?**
Каждый сотрудник подключает его сам на странице {{ui:account.title}}; для администратора он обязателен.
