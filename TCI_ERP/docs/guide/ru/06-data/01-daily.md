## Когда использовать

Каждый день.

## Шаги

1. {{ui:nav.agenda}}: запрос на организацию, запрос отчётности, байер в заявке без организации, заявка на лимит ждёт данных.
2. {{ui:nav.data}} › {{ui:data.views.queue}}: возьмите запрос в работу и выполните его (см. {{link:data-requests}}).

{{shot:data-requests}}

3. {{ui:data.views.proposals}}: байеры, которых клиенты предложили по названию в портале.
4. {{ui:data.views.freshness}}: организации с живыми делами, у которых нет отчётности, отчётность старше 15 месяцев или не хватает реквизитов.

## Результат

Запросы закрыты, заявки на лимиты не ждут данных.

## Частые ошибки

- **Создавать организацию, не проверив дубликаты.** Форма предупреждает о похожих названиях — проверьте их.
