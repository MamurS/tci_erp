Раздел {{ui:nav.limits}} — рабочее место кредитного отдела. Виды переключаются вкладками под заголовком:

| Вид | Что показывает |
|---|---|
| {{ui:limits.views.overview}} | Портфель лимитов: суммы по валютам, диапазонам рейтинга и странам. |
| {{ui:limits.views.queue}} | Заявки к решению: диапазон, сумма в UZS, «в пределах моих полномочий». |
| {{ui:limits.views.inforce}} | Реестр действующих лимитов с фильтрами. |
| {{ui:limits.views.monitoring}} | Пересмотры ≤ 30 дней и просроченные, рейтинг хуже, чем при решении, открытые уведомления о просрочке, группы у предела. |
| {{ui:limits.views.ratings}} | Рейтинги к работе с причиной. |
| {{ui:limits.views.groups}} | Группы и их лимиты. |
| {{ui:limits.views.authority}} | Ваши полномочия по диапазонам. |
| {{ui:limits.views.auto}} | Авторешения по ADT. |

Набор видов зависит от роли: продажи и коммерческий андеррайтинг видят очередь и реестр; кредитный аналитик — аналитические виды без очереди решений.
