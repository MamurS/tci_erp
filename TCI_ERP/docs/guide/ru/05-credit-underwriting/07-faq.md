**Почему моё решение «не записалось»?**
Сумма в UZS выше ваших полномочий для диапазона рейтинга байера. Отправьте решение на валидацию.

**Почему заявка в статусе «Эскалация», хотя я её не отправлял?**
Решение превысило бы лимит группы — заявка поднята для решения с учётом всей группы.

**Нет курса валюты — что делать?**
Без курса UZS сумма не сравнивается с полномочиями. Курс вносит администратор.

**Где история решений по байеру?**
На странице заявки и на вкладке {{ui:entities.tabs.limits}} карточки байера: каждое решение — неизменная строка, новое решение заменяет прежнее.
