## Когда использовать

Каждый день.

## Шаги

1. {{ui:nav.agenda}}: новые претензии, ответы страхователей на запросы сведений, уведомления о просрочке, по которым истёк период ожидания.
2. {{ui:nav.claims}}: очередь претензий по статусам.

{{shot:claims-queue}}

3. {{ui:nav.overdues}}: просрочки, которые могут стать претензией.

## Результат

Каждая претензия движется: проверена, запрошены сведения или принято решение.

## Частые ошибки

- **Терять сроки по уведомлениям.** Поздно поданное уведомление о просрочке лишает покрытия всю претензию — проверяйте даты.
