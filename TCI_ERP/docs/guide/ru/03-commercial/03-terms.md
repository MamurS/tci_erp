## Структура

- **На весь оборот** — покрываются все байеры страхователя (в пределах лимитов и дискреционного лимита).
- **Ключевые байеры** — покрываются только названные байеры.

## Условия

| Условие | Что означает |
|---|---|
| {{term:insured-percentage|Процент покрытия}} | Доля убытка, которую возмещает страховщик, обычно 80–90 %. |
| {{term:nql|Невозмещаемые убытки (NQL)}} | Порог: убыток меньше него не возмещается вовсе; равный порогу — возмещается полностью, без вычета. |
| {{term:deductible|Франшиза}} | Сумма, вычитаемая из каждого убытка после процента покрытия. |
| {{term:afl|Агрегатная франшиза}} | Сумма убытков за период, которую страхователь несёт сам; вычитается её остаток. |
| {{term:max-liability|Максимальный лимит ответственности}} | Предел всех выплат по полису, обычно кратный премии. |
| {{term:dl|Дискреционный лимит}} | До этой суммы страхователь сам оценивает байера без лимита. |
| Период ожидания | Через сколько дней после просрочки можно подать претензию. |
| Максимальная отсрочка платежа | Счета с более долгой отсрочкой не покрываются. |

## Порядок расчёта возмещения

Покрытый долг → порог NQL → × процент покрытия → − франшиза → − остаток агрегатной франшизы → не больше остатка максимального лимита ответственности. Подробно — {{link:claims-coverage}}.
