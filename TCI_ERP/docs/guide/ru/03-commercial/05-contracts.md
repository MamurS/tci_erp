## Когда использовать

Нужно подготовить договор страхования по полису или по заявке.

## Шаги

1. {{ui:nav.policies}} › {{ui:policies.views.contracts}}: выберите полис или заявку и нажмите {{ui:wording.generate.open}}. Нужен активный шаблон договора для страны, языка и продукта.
2. Документ откроется в редакторе. Значения из полиса — это поля-метки; их можно обновить из данных, не трогая текст.
3. Каждое сохранение — новая версия с автором и примечанием. Любые две версии можно сравнить, любую — восстановить (как новую версию).
4. Отправьте на согласование: задача уйдёт коммерческому андеррайтингу. Можно открыть проект клиенту — он увидит именно открытую версию и сможет оставить комментарий.
5. Согласуйте, затем подпишите: загрузите скан подписанного PDF. Подписанный договор заблокирован навсегда.

## Результат

Подписанный договор и вся цепочка версий сохранены; экспорт в DOCX и печать в PDF.

## Частые ошибки

- **Сформировать проект заново поверх ручных правок.** Система спросит подтверждение: ручные правки будут заменены новой версией из шаблона.
- **Править согласованный договор.** Вернуть его в черновик может только коммерческий андеррайтер, с указанием причины.
