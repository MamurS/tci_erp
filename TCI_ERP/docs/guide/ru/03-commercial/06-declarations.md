## Когда использовать

Страхователь подал {{term:turnover-declaration|декларацию оборота}} — или пора начислить премию.

## Шаги

1. {{ui:nav.declarations}}: откройте поданную декларацию.
2. Проверьте строки по байерам. Система делит оборот: по байеру с действующим лимитом покрыт весь оборот; без лимита — только в пределах дискреционного лимита, остальное — **непокрытое превышение** (не застраховано и отдельно показано для коммерческого рассмотрения).
3. Примите декларацию или оспорьте её. При принятии разбивка замораживается, и по покрытому обороту начисляется премия по ставке полиса.
4. Вкладка премии полиса: график рассрочки, счета, платежи. Платёж распределяется на самые ранние взносы; переплата не принимается; ошибка исправляется сторно, а не правкой.

## Результат

Принятая декларация неизменна; исправление — новая декларация, заменяющая прежнюю.

## Частые ошибки

- **Ждать возврата премии ниже минимальной.** Возврата ниже минимальной премии нет.
