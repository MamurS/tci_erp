## Когда использовать

Страхователь хочет сам подавать декларации, заявки на лимиты, уведомления о просрочке и отвечать на предложения через портал.

## Шаги

1. Откройте карточку страхователя, вкладка {{ui:entities.tabs.access}}.
2. Нажмите {{ui:provisioning.inviteClient}}, укажите эл. почту и имя сотрудника клиента.
3. Передайте временный пароль клиенту надёжным способом. При первом входе он сменит пароль.

## Результат

Пользователь клиента видит только свои полисы, лимиты, декларации, премию, просрочки, претензии и предложения.

## Частые ошибки

- **Кнопка недоступна, «сервис подготовки пользователей недоступен».** Сервис создания пользователей пока не размещён; до этого пользователей клиента заводит администратор вручную.
- **Давать клиенту доступ сотрудника.** Роль клиента не совмещается ни с какой другой ролью.
