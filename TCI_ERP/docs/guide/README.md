# User guide

One source, three outputs: the Markdown in this folder is the in-app **Help centre** (`/help` for staff, `/portal/help` for policyholders), the **quick-start PDFs** in `pdf/`, and the contextual help («?» in the top bar, F1, the small «?» beside page titles). Russian is written first and is the reference; English and Uzbek are full translations with the same files. The format mirrors the sister product's manual (MIG Inward Re, `docs/manual`).

## Commands (in `TCI_ERP/`)

| Command | What it does | Needs |
|---|---|---|
| `npm run guide:build` | everything below, in order: shots → content → PDFs → check | Playwright + Chromium |
| `npm run guide:shots` | takes every screenshot in RU / EN / UZ (`e2e/guide/shots.spec.ts`, stubbed backend, network sealed, the recorded demo book with «DEMO …» company names) and records it in `shots/manifest.json` with the app version. `GUIDE_SHOT=<regex>` and `GUIDE_LANGS=ru,en` limit the run. `PW_PORT=4191` when another checkout's dev server already holds 4173 — otherwise Playwright reuses it and photographs THAT checkout. `PW_CHROMIUM_PATH` points at an installed Chromium | Playwright |
| `npm run guide:content` | compiles the Markdown into `src/features/help/content/{ru,en,uz}.json` + `pages.json` (committed, generated — never edit by hand); exits 1 on an error | Node only |
| `npm run guide:pdf` | prints `pdf/<lang>/quick-start-<role>.pdf` for each of the eight roles (`ru` / `en` / `uz` as arguments limit it) | Playwright |
| `npm run guide:check` | the content checks without writing, plus a type check of the e2e project | Node only |

`npm run build` uses the committed bundle, screenshots and PDFs and copies `shots/` and `pdf/` into the site at `/guide/shots/…` and `/guide/pdf/…` (`vite.config.ts`). `npm test` runs the same checks (`scripts/guide/guide.test.ts`).

## A topic

```markdown
---
id: credit-decide             # unique, kebab-case, the same in every language
title: Решение по заявке на лимит
roles: [credit_underwriter]   # sales | commercial_underwriter | credit_analyst | credit_underwriter |
                              # information_manager | claims | admin | client | all (= every staff role)
pages: ["/limits/:id"]        # routes of src/App.tsx it helps with («?», F1)
order: 3
---

## Когда использовать
## Шаги
1. Нажмите {{ui:limits.actions.decide}}.

{{shot:credit-queue}}

## Результат
## Частые ошибки
```

Task headings per language — RU «Когда использовать», «Шаги», «Результат», «Частые ошибки»; EN "When to use it", "Steps", "Result", "Common mistakes"; UZ «Qachon foydalaniladi», «Qadamlar», «Natija», «Ko‘p uchraydigan xatolar». In a role section a topic with «Steps» but not all four prints a warning.

**Who reads what.** Staff read the whole guide; the contents put the acting role's sections first, then `all`, then the rest. A policyholder reads only topics whose roles name `client`, and a portal topic may not link to anything else (checked).

### Tokens

| Token | Becomes |
|---|---|
| `{{ui:nav.limits}}` | the label from `src/i18n/locales/<lang>.json`, bold — «Кредитные лимиты» in RU / UZ, **Credit limits** in EN |
| `{{term:nql}}` / `{{term:nql\|text}}` | the glossary entry (`10-glossary`, a heading `### … {#term-nql}`) |
| `{{link:credit-decide}}` / `{{link:id\|text}}` / `{{link:id#anchor}}` | a link to a topic |
| `{{shot:credit-queue}}` | on its own line: the screenshot for the reader's language |

Markdown: paragraphs, `##`–`####` headings, numbered and bulleted lists, `**bold**`, `*italic*`, `` `code` ``, `<kbd>F1</kbd>`, tables, `---`, `[text](https://…)` and callouts `> [!NOTE]`, `> [!TIP]`, `> [!WARNING]`, `> [!DEMO]`. The Help centre renders the compiled HTML as React elements through an allowlist (`HtmlView.tsx`) — never as an HTML string.

## Checks (`npm test`, `npm run guide:check`)

Errors: front matter (`id`, `title`, `roles`), the same files / ids / roles / pages / order in every language; every `{{ui:…}}` key exists in that language's locale; every term, link and shot exists, the same shots in every language; a shot has its WebP per language and is fresh (its manifest version not lower than `package.json`'s; `GUIDE_ALLOW_STALE=1` turns that into a warning); **every route of `src/App.tsx` is in some topic's `pages`, or in `EXEMPT_ROUTES` with a reason** (`scripts/guide/content.ts`); every `pages` entry is a route; the committed bundle equals a fresh compile; the PDFs exist and are fresh; Uzbek oʻ / gʻ take **‘ (U+2018)** and the tutuq belgisi **’ (U+2019)**, as the uz locale does — never `'`, `ʻ` or `` ` ``; the retired variants of the owner-decided terms (CLAUDE.md glossary: «Покупатель», «Расчётный лимит», «Xaridor», a bare «Bekor qilish», …) never come back; more than 25 stray Latin words in RU (or English words in UZ).

Warnings: fewer stray words, a task without all four headings, term / link tokens that differ between languages, unused shot specs.
