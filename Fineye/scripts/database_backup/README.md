### Структура директорий

    dump.sh     # скрипт для создания дампа
    restore.sh  # скрипт для разворота дампа в БД
    dumps       # директория с дампами
        |_ <container_name>     # имя контейнера из которого был взят дамп
            |_ <database_name>  # название базы данных
                |_ autodump     # для хранения дампов, сделанных автоматически
                |_ handdump     # для хранения дампов, сделанных вручную
                    |_ <database_name>_<date_of_creation>.dump      # сам дамп и формат его названия

### Вызов создания дампа

    ./dump.sh <container_name> <database_user> <database_name> <auto_mode>
    container_name - имя контейнера
    database_user  - имя пользователя БД
    database_name  - название БД
    auto_mode      - режим автоматического создания дампа. По умолчанию отключен. Для взвода опции передать этот аргумент

После вызова, при невзведенном auto_mode, необходимо ввести пароль пользователя <database_user>.

Если не хочется вводить пароль, то необходимо пробросить переменную PGPASSWORD. Для этого существует файл .secrets.sh,
который принимает на вход <container_name> <database_user> и взводит переменную PGPASSWORD для беспарольного доступа.

Чтобы взвести пароль в .secrets, необходимо добавить строку следующего вида:
    
    array[<container_name>][<database_user>]=<password>


Прим. В логе создания дампа присутствует вывод в том числе команды, которая вызывается. По очевидным причинам в выводе
этих строк отсутствует взвод пароля.

### Восстановление из дампа
Допустим, у нас была развернута БД и мы ее удалили:

    DROP DATABASE <database_name>;

Тогда для восстановления необходимо создать БД и дать привелегии пользователю:

    CREATE DATABASE <database_name>;
    GRANT ALL PRIVILEGES ON DATABASE <database_name> TO <database_user>;

А затем восстановить данные из дампа от этого пользователя:

    ./dump.sh <container_name> <database_user> <database_name> <dump_file> <auto_mode>
    dump_file - путь к dump файлу БД
    Остальные параметры аналогичны аргументам dump.sh

Команда копирует в контейнер дамп. Вызывает от пользователя БД pg_restore. После восстановления БД удаляет скопированный
ранее дамп в контейнере.
